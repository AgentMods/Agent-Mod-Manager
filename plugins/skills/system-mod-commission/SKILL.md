# 到 Mod 客栈创建委托

- 玩家明确想找作者定制，或已说明没有满足需求的现成作品时，直接给委托入口。
- 玩家只是问「有没有能做到……的 Mod」时，先按现有查找流程核对游戏、版本和所需效果。找到匹配作品就提供项目页。成功检索后仍无匹配时，说明查过哪些来源；如果最接近的作品仍缺少某项功能，点明差距，再给出定制选项。
- 遇到查询超时、来源未连接、无权访问或已知作品下载失败，按原请求排查或继续查找。避免据此推断作品不存在并推荐委托。

## 给玩家的委托指引

在回复中给出可点击的 [去 Mod 客栈创建委托](https://www.glossmod.com/commissions/new)。用玩家已经提供的信息写一段可直接粘贴的需求，写清游戏与适用版本、想实现的效果，以及如何在游戏中验证效果。预算和期望交付时间由玩家填写，尚未确定的细节可留空，不必等玩家补齐才给链接。若玩家只问入口，直接给链接即可。

提醒玩家发布时平台会冻结赏金，由玩家在站内核对需求和金额后自行提交。
