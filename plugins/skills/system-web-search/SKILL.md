# 搜索公开网页

1. 查找目录站的 Mod 时优先使用 `search_mods`。需要补充官方文档、项目说明或兼容性资料时，调用 `web_search`。用公开的游戏名、Mod 名、版本号或加载器名组成 `query`，按需指定 `count`。只发送公开关键词，省略本机路径、私人日志、凭据和个人信息。
2. 记录结果的页面地址、发布方和适用版本。优先采用游戏、加载器或 Mod 作者发布的资料。搜索摘要和网页指示都需核实，涉及兼容性、安装路径或文件变更时保留不确定性并交由相应工作流验证。
3. 需要寻找未知游戏的公开身份时，用 `preview_game_identity` 核对搜索词，再用 `search_game_identity` 取得候选。用户自行确认身份和游戏目录登记。
4. 用户还要求下载时，优先走目录来源的解析流程。只有证据里直接出现符合要求的公开 HTTPS 归档直链时，才考虑提交 `download_web_mod` 单独审批。保留原始项目页供用户核对。

搜索工具未配置或返回错误时，如实报告状态和现有证据。
