Agent Mod Manager 1.0.1 是一次安全与维护更新，建议 1.0.0 用户升级。

### 更新内容

- **安全加固**：加强 AI 模型目录缓存对不同凭据的隔离，改进本地凭据加密在系统随机数不可用时的处理。现有凭据的存储格式不变。
- **插件发布**：移除详细介绍的单独字符上限，可保留较长的 Markdown 源文；预览和目录仍以普通文本显示，其他包体和字段限制不变。
- **安装包验证**：改进 Windows 安装后的 WebView2 检查，以及从 macOS DMG 复制应用后的启动检查。

### 下载与升级

| 系统 | 安装文件 |
| --- | --- |
| Windows x64 | `-setup.exe` 或 `.msi`，任选其一。需要 WebView2 运行时。 |
| macOS | `.dmg`：Apple Silicon 选 `darwin-aarch64`，Intel 选 `darwin-x86_64`。本版未做 Apple Developer ID 签名或公证，Gatekeeper 可能拦截打开。 |
| Linux x64 | `.AppImage` 或 `.deb`。如果系统没有 FUSE，可尝试 `APPIMAGE_EXTRACT_AND_RUN=1`，或在兼容的 Debian/Ubuntu 系统上选 `.deb`。 |

已安装支持更新的 1.0.0 发行版的用户，可启动应用或在设置中检查更新。更新下载并通过签名验证后，会在正常退出时安装；随后重新打开应用。`latest.json` 和 macOS 的 `.app.tar.gz` 供自动更新使用，不是首次安装文件。
