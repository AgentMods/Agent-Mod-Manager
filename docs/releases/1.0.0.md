Agent Mod Manager 1.0.0 把游戏库、Mod 管理和 AI Agent 放在同一个桌面应用里。可以先从本地导入一个 Mod，也可以让 Agent 查找下载来源，并在确认安装计划后部署。

### 版本亮点

- **游戏库与 Agent 工作区**：扫描或手动登记游戏；每个对话可以关联一款、多款或全部游戏，也可以不关联。可在对话中登记游戏，或修改、移除、启动已登记的游戏，切换工作区不会改变文件权限或审批策略。
- **Mod 管理与恢复**：按游戏归档下载和本地导入的 Mod，支持批量安装、卸载和移除。文件操作遵循所选审批模式，托管操作保留事务记录和覆盖备份，支持事务回滚和回收站恢复。安装后可使用已配置的模型整理 Mod 名称和标签。
- **插件、语言与更新**：插件中心支持安装云端适配包，并在启动时检查已安装的云端适配包更新。界面支持简体中文、英语等 10 种语言。启用更新签名的发行版会在启动时检查应用更新，下载并验证后在正常退出时安装，新版本需手动重新打开。
- **Nexus Mods 下载修复**：内置 Nexus MCP 可为只给出存储路径的文件生成可识别的归档名称；此修复不改变 Nexus 的账号下载权限。

### 下载与安装

从本页 **Assets** 选择与你的系统和处理器匹配的安装包：

| 系统 | 请选择 |
| --- | --- |
| Windows x64 | `-setup.exe`（NSIS）或 `.msi`，任选其一。应用需要 WebView2 运行时。 |
| macOS | `.dmg`：Apple Silicon 选择 `darwin-aarch64`，Intel 选择 `darwin-x86_64`。当前发布流程未配置 Apple Developer ID 签名和公证，Gatekeeper 可能阻止打开。 |
| Linux x64 | `.AppImage` 或 `.deb`。AppImage 如因缺少 FUSE 无法启动，可尝试 `APPIMAGE_EXTRACT_AND_RUN=1` 解包运行，或在兼容的 Debian/Ubuntu 系统上选择 `.deb`。 |

`latest.json` 和 macOS 的 `.app.tar.gz` 供更新器使用；首次安装请选上表所列文件。此前未集成更新器的旧构建需手动安装一次。

### 首次使用与已知限制

- 首次启动可按引导添加游戏。使用 Agent 前，在 **设置 → AI 与模型** 配置兼容 OpenAI Chat Completions 的服务地址和默认模型，并按服务要求填写 API Key。使用第三方 Mod 来源或可选 MCP 工具时，可能需要联网、提供来源凭据，或在来源站点手动下载；内置浏览器首次使用需下载 Chromium。
- 不是所有游戏和 Mod 都能自动部署。有专用加载器、复杂依赖、加载顺序或安装选项的 Mod，请按作者说明手动确认，并在游戏中验证是否生效。
- 加密或分卷 RAR 不支持导入或解压，也不支持创建 RAR。
- 正式桌面版默认发送匿名使用统计。如需关闭，请在启动应用前设置 `AMM_DISABLE_ANALYTICS=1`。
