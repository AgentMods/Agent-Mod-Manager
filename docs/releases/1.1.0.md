Agent Mod Manager 1.1.0 带来 Mod 游览、Mod 资料与更新管理，以及更灵活的游戏启动方式。Agent 安装任务会保留目标游戏和来源信息，并遵循已保存的权限设置；适用的文件替换支持审核与回滚。

### 更新内容

- **游览 Mod**：聚合已连接来源的 Mod 目录，可按游戏和来源筛选、浏览本地化卡片，并通过 Agent 安装任务跟踪进度或继续处理问题。
- **Mod 资料与更新**：记录可确认的版本和作品页面，支持查看资料、维护显示名称与游戏标签、检查新版本。对来源和安装记录经过验证的 Mod，可创建 Agent 审核的替换计划，并在失败时回滚文件变更。
- **游戏启动方式**：在启动菜单中选择可用的 Steam、直接或 Mod 启动器方式；Windows 为部分常见布局提供识别，也可为已登记游戏配置限定在游戏目录内的启动器，不会自动安装启动器。
- **GTA V 可选适配**：仓库提供 Legacy 与 Enhanced 的外部适配包及 RPF 暂存流程；它们不会随桌面应用自动安装或绑定，需单独验证并按游戏版本和适配范围使用。
- **界面与 Agent 工作流**：新增 Home 概览，改进引导、导航和待处理问题/审批提醒；Agent 与授权的 MCP 文件操作可按权限访问当前管理器存储目录。

### 下载与升级

| 系统 | 安装文件 |
| --- | --- |
| Windows x64 | `-setup.exe` 或 `.msi`，任选其一。需要 WebView2 运行时。 |
| macOS | `.dmg`：Apple Silicon 选 `darwin-aarch64`，Intel 选 `darwin-x86_64`。本版未做 Apple Developer ID 签名或公证，Gatekeeper 可能拦截打开。 |
| Linux x64 | `.AppImage` 或 `.deb`。如果系统没有 FUSE，可尝试 `APPIMAGE_EXTRACT_AND_RUN=1`，或在兼容的 Debian/Ubuntu 系统上选 `.deb`。 |

已安装支持更新的 1.0.3 发行版的用户，可启动应用或在设置中检查更新。更新下载并通过签名验证后，会在正常退出时安装；随后重新打开应用。`latest.json` 和 macOS 的 `.app.tar.gz` 供自动更新使用，不是首次安装文件。
