Agent Mod Manager 1.0.3 增加应用更新线路选择。用户可在「设置 → 外观与存储 → 应用更新」中选择默认代理、其他代理或 GitHub 直连；所选线路同时用于获取更新信息和下载安装包。下载仍须通过签名验证后才会安装。

### 更新内容

- **更新线路选择**：提供五条代理线路和 GitHub 直连，默认使用 `cdn.gh-proxy.org`。线路更改从下次检查更新开始生效。
- **安全校验**：更新清单与安装包继续使用签名验证；重定向仅允许预期的 GitHub 发布资源，避免线路跳转到无关来源。

### 下载与升级

| 系统 | 安装文件 |
| --- | --- |
| Windows x64 | `-setup.exe` 或 `.msi`，任选其一。需要 WebView2 运行时。 |
| macOS | `.dmg`：Apple Silicon 选 `darwin-aarch64`，Intel 选 `darwin-x86_64`。本版未做 Apple Developer ID 签名或公证，Gatekeeper 可能拦截打开。 |
| Linux x64 | `.AppImage` 或 `.deb`。如果系统没有 FUSE，可尝试 `APPIMAGE_EXTRACT_AND_RUN=1`，或在兼容的 Debian/Ubuntu 系统上选 `.deb`。 |

已安装支持更新的 1.0.2 发行版的用户，可启动应用或在设置中检查更新。更新下载并通过签名验证后，会在正常退出时安装；随后重新打开应用。`latest.json` 和 macOS 的 `.app.tar.gz` 供自动更新使用，不是首次安装文件。
