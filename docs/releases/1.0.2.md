Agent Mod Manager 1.0.2 新增 Thunderstore 模组来源 MCP。可在「设置 → 工具」启用后，让 Agent 浏览社区与模组版本、查看依赖，并下载指定版本。

### 更新内容

- **Thunderstore 来源**：无需 API Key，可按社区搜索模组、核对作者与精确版本、查看版本信息和依赖。
- **受管下载**：下载的 ZIP 保存到管理器的 `downloads/incoming` 收件目录，并返回文件路径、大小和 SHA-256。后续仍按正常审批与入库流程处理；下载不会自动安装到游戏。
- **首次连接**：首次启动 Thunderstore MCP 需要联网准备组件。升级后重新启动该内置工具时，应用会要求确认更新后的启动配置。

### 下载与升级

| 系统 | 安装文件 |
| --- | --- |
| Windows x64 | `-setup.exe` 或 `.msi`，任选其一。需要 WebView2 运行时。 |
| macOS | `.dmg`：Apple Silicon 选 `darwin-aarch64`，Intel 选 `darwin-x86_64`。本版未做 Apple Developer ID 签名或公证，Gatekeeper 可能拦截打开。 |
| Linux x64 | `.AppImage` 或 `.deb`。如果系统没有 FUSE，可尝试 `APPIMAGE_EXTRACT_AND_RUN=1`，或在兼容的 Debian/Ubuntu 系统上选 `.deb`。 |

已安装支持更新的 1.0.1 发行版的用户，可启动应用或在设置中检查更新。更新下载并通过签名验证后，会在正常退出时安装；随后重新打开应用。`latest.json` 和 macOS 的 `.app.tar.gz` 供自动更新使用，不是首次安装文件。
