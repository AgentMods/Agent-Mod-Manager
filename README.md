# Agent Mod Manager


Agent Mod Manager（AMM）是一款由 AI Agent 驱动的智能游戏 Mod 管理器，内置了国内外7家Mod平台的资源，由AI根据你的需求自动查找并安装使用。支持一键创建游戏适配包，一键下载、安装、卸载、删除 任意Mod，自动重命名整理，

### 功能
- 自动扫描游戏库中支持的游戏
- 一键查找、下载、安装、卸载、删除 您的Mod
- 适配任意游戏的任意Mod
- 一键创建游戏适配包，无需任何技术门槛
- 国内外7家Mod平台资源，AI一键全部查找
- 自适应主题
- 自适应语言
- 简介的UI
- 免费开源
- 无毒无捆绑
- 功能全部免费开放
